# Neon Fortune Slots demo

- Local demo currency: 100 DP per page load
- Layout: 5 reels × 3 rows
- Win system: 10 fixed paylines, evaluated left to right
- Match: 3 or more identical symbols from the first reel
- Wild: substitutes for every regular symbol
- Total bet options: 1, 2, 5, 10, 20 DP
- Deferred: scatter, free spins, jackpot, autoplay and server settlement

The demo deliberately keeps wallet state and random outcomes in the browser. A live version must move the result generation, bet validation and wallet settlement to a trusted server.
